# IndustrialProgramming_lab2
Repository for 2nd lab of Industrial Programming

# Класс Platform
Класс отвечает за описание поведения объектов-платформ

# Класс Player
Класс отвечает за описание поведения персонажа игрока в различных ситуацияях

# Класс Mele_attack
Класс отвечает за описание поведения атаки ближнего боя у игрока

# Класс Ghost
Класс отвечает за описание поведения врага - Лича

# Класс Level
Класс отвечает за описание поведения уровня, на котором находится игрок

# Классы Healthbar_red и Healthbar_green 
Классы отвечают за описание поведение полосы жизней игрока

# Файл 2D_dungeon.py
Файл отвечает за работу всей игры - собирает все механики воедино
